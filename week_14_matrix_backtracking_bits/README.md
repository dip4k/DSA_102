# 📓 Week 14 Study Guide: Matrices, Bitmasks & Number Theory

This folder contains the complete, highly comprehensive learning package for Week 14. 

---

## 🎯 Weekly Goal
Master specialized problem domains—including multi-dimensional matrix transformations, register-level bit operations, modular arithmetic number theory, and advanced non-backtracking string algorithms—by developing rigorous index metrics, cache prefetching awareness, and state-machine transitions.

---

## 📅 Folder Contents & Study Plan

### 🚀 Curriculum Day-by-Day Guides
*   **Day 1: Matrices & Shuffling**
    *   File: [Week_14_Day_01_Matrix_Operations_Instructional.md](Week_14_Day_01_Matrix_Operations_Instructional.md)
    *   *Core Mechanics*: Transpose, 90-degree rotations, spiral walks, staircase search, set matrix zeroes, and Gaussian elimination.
*   **Day 2: Bitwise Registers & Subsets**
    *   File: [Week_14_Day_02_Bitwise_Operations_Instructional.md](Week_14_Day_02_Bitwise_Operations_Instructional.md)
    *   *Core Mechanics*: AND/OR/XOR operators, isolating lowest set bit (`n & -n`), Brian Kernighan popcounting, submask decrement loops, and Gray code configurations.
*   **Day 3: Primes & Modular Exponentiation**
    *   File: [Week_14_Day_03_Number_Theory_Basics_Instructional.md](Week_14_Day_03_Number_Theory_Basics_Instructional.md)
    *   *Core Mechanics*: Euclidean GCD/LCM, Sieve of Eratosthenes, logarithmic modular powering (O(log e)), and Fermat's Little Theorem modular inverses.
*   **Day 4: Non-Backtracking String Matching**
    *   File: [Week_14_Day_04_Advanced_Strings_Instructional.md](Week_14_Day_04_Advanced_Strings_Instructional.md)
    *   *Core Mechanics*: KMP string matching & LPS precomputation, character Tries, stable Radix Sorting, and Aho-Corasick automaton loops.
*   **Day 5: Advanced Number Theory (Optional)**
    *   File: [Week_14_Day_05_Advanced_Number_Theory_Instructional.md](Week_14_Day_05_Advanced_Number_Theory_Instructional.md)
    *   *Core Mechanics*: Euler's Totient coprime counts phi(N), and Chinese Remainder Theorem (CRT) equation solvers.
