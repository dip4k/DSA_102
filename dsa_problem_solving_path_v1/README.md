## 💡 Success Strategies

### Problem-Solving Framework
1. **Understand**: Read problem 2-3 times, note constraints
2. **Identify Pattern**: Which pattern does this belong to?
3. **Brute Force**: Get a working solution first
4. **Optimize**: Can we improve time/space complexity?
5. **Code**: Write clean, tested solution
6. **Verify**: Test with examples + edge cases
7. **Analyze**: Calculate time and space complexity

### Pattern Recognition Tips
- Arrays sorted? → Consider **Binary Search**
- Find pairs/triplets? → Consider **Two Pointers**
- Subarray/substring? → Consider **Sliding Window**
- Tree/Graph traversal? → Consider **DFS/BFS**
- Optimization problem? → Consider **DP or Greedy**
- Generate combinations? → Consider **Backtracking**
- Top-K elements? → Consider **Heap**
- Range queries? → Consider **Prefix Sum**

### Common Pitfalls to Avoid
- ❌ Jumping to code without clear plan
- ❌ Ignoring edge cases (empty, single element, duplicates)
- ❌ Not analyzing complexity before coding
- ❌ Memorizing solutions instead of patterns
- ❌ Skipping review sessions
- ❌ Solving too many problems without mastery
- ❌ Not practicing under timed conditions
