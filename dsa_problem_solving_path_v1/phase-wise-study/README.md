## File roles

### Main files
Main files are the long-form narrative study files.
Use them to understand the phase goals, mental models, topic structure, and integration logic.

### Learning accelerators
Learning accelerators are condensed companions for faster execution.
Use them when you want a higher-ROI review path instead of reading the full narrative again.

### Supplementary accelerators
Supplementary accelerator files are the fast-track revision and execution layers for later phases.
Use them when you want prioritization, short revision loops, and practical study guidance.

## Best way to use this set
- Start with the main file for the phase you are studying.
- Open the paired accelerator after the main file when one exists.
- Use the later-phase supplementary files for fast revision, interviews, and execution-focused review.
- Keep this README as your top-level navigation page.
