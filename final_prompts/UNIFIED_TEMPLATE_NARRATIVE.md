# Unified Narrative Template

Required heading style
- Use clear emoji-enhanced section markers for learner readability.

Title block
- Week/day/topic metadata
- Learning objectives
- Weekly goal linkage and prerequisites

## Chapter 1: Context and Motivation
- Engineering problem and constraints
- Why naive approaches fail
- Solution preview and core insight
- One short real-world anchor to establish relevance

## Chapter 2: Mental Model
- Core analogy
- Invariants and structure
- Variation taxonomy table
- Common confusion points and corrections

## Chapter 3: Mechanics
- Step-by-step logic flow
- Trace examples and edge cases
- Common failure patterns
- At least one wrong-approach contrast

## Chapter 4: Performance and Systems
- Complexity table (time and space)
- Practical trade-offs (constants, memory, cache, implementation complexity)
- Real-system case studies (2+ concise cases)

## Chapter 5: Integration and Mastery
- Pattern selection rules
- Interview framing and follow-ups
- Reflection questions and retention hook
- Basic -> medium -> advanced variation path

Supplementary blocks
- Practice problems (progressive ladder)
- Interview questions (with follow-up prompts)
- Misconceptions and corrections
- Advanced extensions
- External resources

Quality anchors
- Topic/subtopic coverage must match day scope from syllabus.
- Content should feel continuous and cumulative, not fragmented.
- Use concise visuals/tables where they improve understanding.
