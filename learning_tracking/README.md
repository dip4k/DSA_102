# Learning Tracking Workspace

This folder tracks practice execution, weak areas, and interview readiness.

Files
- Practice_Log.md: day-by-day solved and attempted problems.
- Question_Bank.md: mistakes, pattern misses, and reattempt queue.
- Weekly_Review.md: weekly reflection and gap analysis.
- Mock_Interview_Log.md: mock sessions and communication feedback.

Recommended Daily Flow
1. Solve 2-5 problems.
2. Log each attempt in Practice_Log.md.
3. Add mistakes and retries in Question_Bank.md.
4. End the week with Weekly_Review.md.

Recommended Weekly Flow
1. Run one mock interview.
2. Record strengths/weaknesses in Mock_Interview_Log.md.
3. Plan next week's top 3 focus patterns.
