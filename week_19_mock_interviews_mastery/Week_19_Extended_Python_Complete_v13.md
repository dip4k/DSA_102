# Week 19 Extended Python Complete v13

Purpose: give Python-focused execution guidance for mock interviews, communication, and timed practice.

## Focus tags
- Must: clear narration, invariant-first coding, edge-case communication, Python standard-library judgment
- Should: quick template recall and debugging discipline
- Optional: mock-review rubrics and refactor quality

## Python interview checklist
- State the algorithm before typing.
- Name the invariant explicitly.
- Choose built-ins (`deque`, `heapq`, `dict`, `set`) deliberately and explain why.
- Handle empty, single-element, and boundary cases early.
- Say when Python recursion depth is a practical risk.

## Mock-round skeleton
1. Clarify input, constraints, and output.
2. Propose 1-2 approaches, choose one.
3. State time/space complexity before coding.
4. Implement the simplest correct version.
5. Dry-run on a small example.
6. Call out edge cases and follow-ups.

## Practice ladder
- Arrays/strings round

- DP/optimization round
- Mixed design-style algorithm round
