# 🧠 DSA Traversal & Problem Solving Curriculum 2.0

> **Philosophy:** Build an index/state mental model that lets you *derive* the traversal when you see a new problem — not memorize templates.

Every guide follows the same structure:
- **Summary Table** → Quick-scan of levels, mental models, and drill problems
- **Mental Model & Invariants** → What does the state/index mean? What region is processed?
- **Visual State Transitions** → Step-by-step markdown tables tracing pointer/state changes
- **Code Snippets** → Python + C# with problem descriptions and inline comments
- **⚠️ Gotchas & Pitfalls** → Common edge cases and bugs at every level
- **Drill Problems** → Tagged LeetCode problems with difficulty ratings
