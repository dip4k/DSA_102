# Graphs Traversal README

Use this folder for graph exploration, shortest-path thinking, and traversal drill work.

Canonical file:
- `Graphs_Traversal_Mastery_Unified_Guide_v4.md` : the single merged guide for concepts, visuals, practice ladders, and advanced extensions

Coverage tags:

- `Should` : shortest paths, SCC, bridges/articulation, MST
- `Optional` : Bellman-Ford, Floyd-Warshall, A*, max flow, matching, and other advanced graph extensions

Recommended study flow:
1. Read the unified guide level by level.
2. Use the embedded practice ladder after each level.
3. Treat all former companion files as merged into the canonical guide.
