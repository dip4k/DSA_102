# Traversal Guides Index

This folder is the consolidated practice-and-mastery track for traversal-heavy DSA work.

Canonical learning flow:
1. Pick a domain.
2. Read the domain `README.md` first.
3. Study the mastery guide.
4. Use the drills/practice set.
5. Review the visual playbook.

Domains:
- `arrays/` : linear scans, two pointers, windows, partitioning, answer-space search.
- `graphs/` : BFS, DFS, topological sort, shortest paths, SCC, MST patterns.
- `linked lists/` : traversal, rewiring, reverse, fast/slow, merge patterns.
- `queues/` : queue/deque traversal, BFS-style movement, monotonic deque foundations.
- `sorting/` : merge-style traversal, quicksort/mergesort movement, interval-style merge patterns.
- `stacks/` : stack movement, monotonic stacks, parsing, range contributions.
- `strings/` : cursor walking, windows, parsing, pattern matching, Unicode/performance awareness.
- `Trees/` : DFS/BFS orders, views, Morris traversal, tree-specific drill ladders.
